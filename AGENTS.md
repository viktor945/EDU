# STEPLine EDU — инструкции для разработки

## Начальная ориентация

Прочитай `docs/PROJECT_CONTEXT.md`, `docs/ARCHITECTURE.md`, `docs/STATUS_AND_NEXT_STEPS.md`, `docs/RECENT_CHANGES.md`, `SERVER_TRANSFER.md` и `docs/EXPORT_STATUS.md`. Это передача существующего продукта, не задание создать новый сайт.

## Правила продукта

- Все общие исправления относятся к детским садам, школам, колледжам и университетам. Опирайся на `app/institutions.ts`; не зашивай школьные названия во все профили.
- Данные, оформление, разделы, файлы и профили экранов изолируются по учреждению. Настройка одной организации не меняет остальные.
- Создание учреждения разрешено только владельцу платформы. Проверка должна работать в API, включая случаи, когда пользователю назначили `*` на уровне своей школы.
- Директор/завуч объединены в `school_head`. Название зависит от типа учреждения. IT-специалист — должность; набор прав назначается отдельно.
- Редактирование и публикация должны сохраняться на сервере и отражаться на публичном портале. Не подменяй это локальными заглушками.
- Одна общая иерархия меню в админке и публичном портале. При смене раздела меню не должно прыгать или временно становиться школьным для другого типа учреждения.
- Режим устройства ограничивает открываемые разделы и внешний переход. Системную блокировку выхода реализует ОС/MDM, не JavaScript.
- QR-коды контактов информационные. На публичном экране не должно быть переходов в сторонние приложения/вкладки.
- Все фотографии и схемы при полноэкранном просмотре показывать целиком в доступной области, без обрезки и прокрутки картинки. Повторное нажатие закрывает просмотр.
- Адаптивность определяется доступным пространством, а не конкретной моделью телефона. Поддерживать сенсорное управление, компактное меню и доступный выход из аккаунта.
- RU/KZ/EN: выбранный язык админки определяет ввод оригинала; две остальные версии доступны отдельно. Язык отображения опций не должен изменять их канонические значения.
- Не обнуляй существующие ручные переводы и прикреплённые языковые файлы.
- Офлайн-копия сохраняется после загрузки всех её файлов/страниц. Пропадание сети не должно заменять исправную копию неполными данными.
- Скорость бегущей строки независима от смены слайдов; не сбрасывать позицию на каждом рендере/замере. Не использовать JS/setInterval для покадрового перемещения текста.

## Работа с кодом и данными

Сохраняй существующий визуальный стиль и функции. Выполняй изменения в рамках запроса; избегай массовой смены стека. Упоминание в проектном контексте не означает, что функция прошла проверку на реальном устройстве — сверяйся с кодом и статусом.

Сервер сейчас использует Cloudflare Worker, `env.DB` (D1), `env.BUCKET` (R2). Стандартный Node-сервер потребует адаптера. Авторизация зависит от доверенного заголовка хостинга; не подделывай его для обхода входа и не доверяй ему от обычного клиента при переносе.

Не добавляй в Git ключи, сессии, резервные копии рабочих данных или каталог `transfer/` с персональными записями. Файлы передачи уже содержат предупреждение об ограниченной полноте. Перед инициализацией Git проверь `.gitignore`.

При изменении кешируемого клиентского кода согласованно обновляй статический cache в `app/offline-cache.ts`, `public/portal-sw.js` и версию манифеста `scripts/build-offline-manifest.mjs`. Текущая ревизия кеша — 38.

## Проверки

Node >=22.13. Linux/WSL нужен для shell-скриптов с `timeout` и `flock`. Команды: `npm ci`, `npm run dev`, `npx tsc --noEmit`, `npm run build`.

Существующие проверки выбирай по изменённому поведению:

- `node tests/content-integration.cjs` — API, публикация, права, импорт, изоляция учреждений, календарь, устройства.
- `node tests/experience.cjs` — часы, смены, интервалы, формат таймера, баннеры, настройки.
- `node tests/offline-and-languages.cjs` — языковые шаблоны, значения опций, языковые версии, офлайн-кеш.
- `node tests/ticker-motion.cjs` — скорость и непрерывность движения строки.
- `node --test tests/rendered-html.test.mjs` — после сборки.

Эти тесты содержат собственные заглушки/данные и не заменяют проверку на физических панелях. Не запускай изменяющие production данные команды ради тестирования.
