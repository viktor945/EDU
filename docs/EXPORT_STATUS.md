# Состояние выгрузки рабочих данных

Подготовлено 3 ноября 2026 года. Рабочий сайт остаётся на прежнем хостинге; упаковка не удаляла и не переносила его данные.

## Полностью включено

Все 454 отслеживаемых файла исходной ревизии b5bcf720a9eeba8a8e757057611331c329ec00da, включая прикладной код, миграции, package-lock, исходные статические изображения интерфейса и все готовые Excel-шаблоны. Дополнительно подготовлены инструкции и контекст для Codex. В копии .gitignore добавлено исключение /transfer/ для рабочих выгрузок.

## Вспомогательная выгрузка таблиц

Файл database-inspection.partial.json содержит полученные страницы девяти таблиц, без записи в базу. Пагинация пройдена до конца по возвращаемым указателям. Непоместившиеся строки предыдущей страницы получались на следующих страницах; это не потерянные строки.

| Таблица | Получено строк | Обрезанных значений |
| --- | ---: | ---: |
| app_operations | 3 | 0 |
| content_items | 106 | 2 |
| display_devices | 0 | 0 |
| display_profiles | 0 | 0 |
| files | 43 | 0 |
| members | 5 | 0 |
| schools | 6 | 1 |
| translation_cache | 0 | 0 |
| translation_usage | 0 | 0 |

В сумме обрезаны **три значения ячеек**: одно в schools и два в content_items. Это ограничение инструмента чтения; в работающей базе полные значения остаются. Сохранены проекции со смещениями и отметками обрезки. Эта выгрузка помогает изучить структуру и записи, но **не является полным SQL-дампом или безопасным источником восстановления**.

Попытка получить полную административную выгрузку через обычный API вернула 401: текущая серверная сессия в архив не переносится. Заголовки идентичности не подделывались. Не обходите авторизацию ради получения копии.

## Не включено

- Бинарные объекты 43 пользовательских загрузок из R2: фотографии, планы, документы и другие файлы. В JSON есть их метаданные и object_key, но это не сами файлы.
- Полный согласованный backup D1 со всеми значениями, структурой и служебным состоянием.
- Серверные секреты и подключённые аккаунты: ключ перевода, cookies, сессии, токены доступа.
- Полная Git-история и установленные npm-зависимости. Исходники точной последней ревизии включены.
- Буквальная стенограмма старого чата и отсутствующие исторические вложения. Требования и решения переданы в docs/PROJECT_CONTEXT.md.

## Для продолжения в Codex

Исходников достаточно для продолжения разработки. Можно работать с тем же облачным сайтом при наличии разрешённого доступа к Sites: переезд в Codex сам по себе не переносит production-данные и не требует смены хостинга.

Для нового независимого сервера попросите владельца текущего хостинга выгрузить полный D1 backup и все R2 objects. Сопоставляйте файлы по object_key, сохраняйте id/school_id/file_id, отдельно проверяйте переводы и layouts. Сначала восстановите копию в тестовой среде. Не заменяйте частичным JSON рабочую базу.

Выгрузка может содержать персональные контакты. Она оставлена только внутри архива передачи, не добавлялась в исходный репозиторий сайта и исключена из нового Git через .gitignore. Если передаёте архив третьим лицам, учитывайте его содержимое.
