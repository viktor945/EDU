# Недавние изменения

## Версия 38 — бегущая строка

Причина обращения: текст двигался рывками. Реализован отдельный механизм Web Animations API в `app/ticker-motion.ts`: линейное движение через `translate3d`, сохранение позиции при изменении размеров и смене скорости, защита от лишнего пересоздания при небольших дробных расхождениях замера. Для старых браузеров предусмотрена CSS-анимация.

`Ticker` мемоизирован и измеряет размеры через ResizeObserver с объединением замеров. Показ слайдов не должен заново запускать строку. Два одинаковых набора текста обеспечивают непрерывный цикл; сообщения из новых строк разделены промежутком 12ch. Полоса прогресса слайда меняет `scaleX`, а не ширину на каждом кадре. Обновлён cache revision до 38.

Тест: `tests/ticker-motion.cjs`. Состояние — опубликовано; проверка именно физической панели пользователем ещё не подтверждена.

## Версия 37 — формат обратного отсчёта

`formatCountdown` в `app/lesson-clock-model.ts`: от 3600 секунд выводятся часы, минуты и секунды. Например, `125:30` стало `02:05:30`; `45:00` осталось `45:00`. Общий компонент используется в шапках, на главной, мобильном дашборде и экране устройства. Обновлена офлайн-оболочка.

## Версия 36 — три языка, офлайн, передача исходников

Админка RU/KZ/EN, язык исходного ввода, сохранение предыдущего оригинала отдельной версией, переведённые Excel-шаблоны/значения опций. Текст слайда до 270 символов, меньший шрифт. Офлайн-копии публичных данных, медиа и оболочки с синхронизацией раз в четыре минуты. Дополнительно учтены картинки в layout главной и доступ к ним. Подготовлен `SERVER_TRANSFER.md`.

Промежуточная версия 35 сохранялась до дополнительных исправлений; исходить из итоговой 36 и следующих, не откатываться к 35.

## Версия 34 — организация админского контента

Баннеры перенесены в «Контент портала → Главная», компактные раскрывающиеся настройки. Режим ожидания перенесён в контент и разделён на слайд-шоу/бегущую строку. Улучшена читаемость настроек часов/региона. Между строками бегущего текста убраны длинные пустые паузы.

## Версия 33 — общая логика показа

Общие часы с таймером, адаптация мобильного сценария ученика, настройки дополнительных разделов. Баннеры из конфигурации и опубликованных материалов главной объединены. Календарь перенесён в события; важные объявления — на главную. Миграция старых записей безопасности сделана идемпотентной, с сохранением связей и переводов.
