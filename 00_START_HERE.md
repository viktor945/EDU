# STEPLine EDU — продолжение работы в Codex

Пакет подготовлен 3 ноября 2026 года. Исходники соответствуют опубликованной версии **38**, commit `b5bcf720a9eeba8a8e757057611331c329ec00da`.

1. Распакуйте архив на компьютер.
2. Откройте в Codex папку **STEPLine-EDU**, в которой лежат `package.json` и `AGENTS.md`.
3. Скопируйте в новый чат текст из **CODEX_START_PROMPT.md**.

Codex получит исходники и проектные инструкции из этой папки. Сам старый чат автоматически в новый чат не переносится: его решения и требования собраны в `docs/PROJECT_CONTEXT.md`, история последних изменений — в `docs/RECENT_CHANGES.md`.

## Запуск

Текущая среда — React/TypeScript/Vinext и Cloudflare Worker с D1/R2. Это серверное приложение. Для Linux или WSL с Node.js >=22.13:

```bash
npm ci
npm run dev
```

Эти команды запускают среду разработки, но **не подключают автоматически рабочую базу и загруженные клиентами файлы**. Для локального просмотра нужно настроить локальную базу по миграциям и тестовые данные либо отдельную разрешённую среду. Без этого интерфейс может показывать отсутствие данных; это не означает, что опубликованный портал пустой.

Переезд в Codex не требует сразу менять хостинг. Можно продолжать разработку этого же Sites-проекта с прежним доменом и данными при наличии доступа. Если затем понадобится перенос на собственный сервер, сначала изучите `SERVER_TRANSFER.md`: авторизация, база и хранилище требуют адаптации.

В архиве нет `node_modules`, секретов, cookies и настроенных пользовательских сессий. Исходники и статические изображения/шаблоны включены полностью; доступность рабочих данных отдельно указана в `docs/EXPORT_STATUS.md`. Полная Git-история не включена; текущая точная ревизия сохранена в manifest.
